# 결제·관리자 설정 안내 (처음부터 순서대로)

코드는 다 들어가 있어요. 아래는 계정을 만들고 값을 넣는 일이라 직접 해 주셔야 해요. 1~7단계를 순서대로 하면 한 시간 안에 끝나요. 모두 무료로 할 수 있어요.

## 어떻게 동작하나요

| 누가 | 볼 수 있는 것 | 비용 |
|---|---|---|
| 결제 전(누구나) | 추천 이름 **3개**, 총평, 만세력 | 무료 |
| 일반 사용자 | 결제한 분석의 추천 이름 전체, 항목별 자세한 풀이·고쳐 보기, 더 좋은 한자 | **분석 1회 990원** |
| 관리자 | 결제 화면은 똑같이 보이고, **관리자 번호**를 넣으면 결제 없이 전부 | 0원 |

**1회 = 분석 1건**이에요.
- 분석 한 건은 "성 + 아이 정보(성별·생일·시각·지역) + 이름 조건 + 계산 기준"의 한 묶음이에요.
- 결제한 분석은 로그인하면 **언제든 다시 볼 수 있어요**. 그 결과에 나온 이름의 풀이도 함께 열려요.
- 위 묶음 중 하나라도 **바꾸면 새 분석**이라 다시 결제해요(예: 생일을 고침, 이름 느낌을 바꿈, 정통→실용 기준으로 바꿈). 정렬(점수순·가나다순)만 바꾸는 것은 같은 분석이에요.
- 가격은 `apps/worker/wrangler.toml`의 `PRICE_KRW`에서 바꿔요.

**결제 수단**: 토스페이먼츠 결제창을 써요. 카드와 함께 **카카오페이·네이버페이·토스페이**를 결제창 안에서 고를 수 있어요(토스와 계약한 수단만 보여요). 카카오페이를 따로 붙일 필요가 없어요.

**관리자 번호**: 어디에도 적혀 있지 않은 일회용 6자리 번호예요. 결제 화면에서 '관리자 번호 받기'를 누를 때마다 서버가 새로 만들어 **내 휴대폰으로** 보내요. 5분 안에 한 번만 쓸 수 있고, 넣으면 12시간 동안 결제 없이 전부 볼 수 있어요(`ADMIN_PASS_HOURS`로 바꿈). '관리자 모드 끄기'를 누르면 일반 사용자 화면으로 돌아가요.

## 1단계. Cloudflare 가입하고 값 두 개 복사하기 (사이트를 올릴 곳, 무료)

1. https://dash.cloudflare.com/sign-up 에서 이메일·비밀번호로 가입하고, 받은 메일의 확인 링크를 눌러요.
2. 로그인한 화면 왼쪽 메뉴에서 **Workers & Pages**를 눌러요. 처음이면 하위 도메인 이름을 정하라고 나와요. 영문으로 아무 이름이나 정해요(예: `abc`). 나중에 사이트 주소가 `https://aidam.abc.workers.dev`가 돼요.
3. 같은 화면 오른쪽에 **Account ID**가 보여요. 옆의 복사 버튼을 눌러 메모장에 붙여 둬요. → **값 ①**
4. 오른쪽 위 사람 모양 아이콘 → **My Profile** → 왼쪽 **API Tokens** → **Create Token**을 눌러요.
5. 목록에서 **Edit Cloudflare Workers** 줄의 **Use template**을 눌러요.
6. 아래쪽 **Account Resources**는 `Include` / 내 계정, **Zone Resources**는 `Include` / `All zones`로 고르고 **Continue to summary** → **Create Token**을 눌러요.
7. 화면에 나온 긴 글자(토큰)를 복사해 메모장에 붙여 둬요. 이 화면을 닫으면 다시 볼 수 없어요. → **값 ②**

## 2단계. 토스페이먼츠 가입하고 테스트 키 두 개 복사하기

1. https://developers.tosspayments.com 에서 회원가입하고 로그인해요.
2. 오른쪽 위 **내 개발정보**(또는 **API 키**)로 들어가요.
3. **API 개별 연동 키** 칸에서 테스트용 키 두 개를 복사해 메모장에 붙여 둬요. ('결제위젯 연동 키'가 아니에요.)
   - **클라이언트 키** (`test_ck_`로 시작) → **값 ③**
   - **시크릿 키** (`test_sk_`로 시작) → **값 ④**
4. 테스트 키로는 실제 돈이 나가지 않아요. 실제 결제는 9단계에서 바꿔요.

## 3단계. 관리자 번호를 받을 휴대폰 준비하기 (무료)

휴대폰 알림으로 받는 방법이에요. 문자(SMS)로 받고 싶으면 아래 "문자로 받기"를 보세요.

1. 휴대폰의 Play 스토어(안드로이드)나 App Store(아이폰)에서 **ntfy** 앱을 설치해요.
2. 앱을 열고 **+** 버튼(구독 추가)을 눌러요.
3. **Topic name**(주제 이름) 칸에 남이 맞히기 어려운 긴 이름을 영문·숫자로 지어 넣어요. `aidam-` 뒤에 아무 글자나 20자 이상 붙이면 돼요(예: `aidam-k3v9x2m7q1w8z5t4r6y0`). 이 예시를 그대로 쓰지 말고 직접 지어 주세요.
4. 서버 주소는 그대로(ntfy.sh) 두고 **Subscribe**(구독)를 눌러요. 알림 허용을 물으면 허용해요.
5. 방금 지은 주제 이름을 메모장에 적어 둬요. → **값 ⑤**

이 이름을 아는 사람만 번호를 볼 수 있으니 다른 곳에 적지 마세요. 번호가 새어 나가도 관리자 Google 계정으로 로그인해야만 쓸 수 있어요.

<details>
<summary>문자로 받기 (선택, 건당 요금)</summary>

문자를 보내려면 문자 발송 서비스가 필요해요. [솔라피](https://solapi.com)에 가입해 **발신번호 등록**(본인 휴대폰 인증)과 **충전**을 하고, **API Key**와 **API Secret**을 만들어요. 그런 다음 4단계 표에 아래 네 개를 더 넣으면 알림 대신 문자로 가요.

| Secrets 이름 | 값 |
|---|---|
| `SOLAPI_API_KEY` | 솔라피 API Key |
| `SOLAPI_API_SECRET` | 솔라피 API Secret |
| `SMS_FROM` | 등록한 발신번호(숫자만, 예: 01012345678) |
| `ADMIN_PHONE` | 번호를 받을 내 휴대폰(숫자만) |

</details>

## 4단계. GitHub에 값 넣기

1. https://github.com/makerskim/aidam 에 로그인한 채로 들어가요.
2. 위쪽 탭에서 **Settings**(톱니바퀴) → 왼쪽 메뉴 **Secrets and variables** → **Actions**를 눌러요.
3. **Variables** 탭을 누르고 **New repository variable**로 아래 두 개를 하나씩 넣어요. Name에 이름, Value에 값을 붙여 넣고 **Add variable**.

| Name | Value |
|---|---|
| `CLOUDFLARE_ACCOUNT_ID` | 값 ① (Account ID) |
| `TOSS_CLIENT_KEY` | 값 ③ (`test_ck_…`) |

4. **Secrets** 탭을 누르고 **New repository secret**으로 아래 네 개를 하나씩 넣어요.

| Name | Secret |
|---|---|
| `CLOUDFLARE_API_TOKEN` | 값 ② (Cloudflare 토큰) |
| `TOSS_SECRET_KEY` | 값 ④ (`test_sk_…`) |
| `NTFY_TOPIC` | 값 ⑤ (ntfy 주제 이름) |
| `ADMIN_EMAILS` | 관리자로 쓸 내 Google 계정 이메일 |

이름은 대문자·밑줄까지 똑같이 넣어야 해요. 값은 채팅이나 코드에 붙여 넣지 말고 여기에만 넣어 주세요.

## 5단계. 배포하기

1. 저장소 위쪽 탭 **Actions**를 눌러요.
2. 왼쪽 목록에서 **Cloudflare**를 누르고, 오른쪽 **Run workflow** → 초록색 **Run workflow**를 눌러요.
3. 3~5분 기다려요. 목록 맨 위 줄에 초록색 체크가 뜨면 성공이에요. 빨간 X가 뜨면 그 줄을 눌러 나오는 오류 글을 그대로 알려 주세요.
4. https://dash.cloudflare.com → **Workers & Pages** → **aidam**을 누르면 사이트 주소(`https://aidam.….workers.dev`)가 보여요. 이 주소를 메모해요. → **값 ⑥**

이때 저장소(KV)와 서명 키가 자동으로 만들어져요. 앞으로는 코드가 바뀔 때마다 자동으로 다시 배포돼요.

## 6단계. Google 로그인이 새 주소에서 되게 하기

1. https://console.firebase.google.com 에 들어가 **aidam** 프로젝트를 눌러요.
2. 왼쪽 메뉴 **빌드 → Authentication** → 위쪽 **설정** 탭 → **승인된 도메인** → **도메인 추가**를 눌러요.
3. 값 ⑥에서 `https://`를 뺀 부분(예: `aidam.abc.workers.dev`)을 넣고 **추가**를 눌러요.

## 7단계. 잘 되는지 확인하기

새 주소(값 ⑥)로 들어가서 해 봐요.

1. **결제 전**: 로그인하지 않고 이름을 추천받아요. 3개만 보이고 '이 분석 전체 보기 990원'이 나오면 정상이에요.
2. **결제**: 그 버튼 → 로그인 → 결제하기. 테스트 키라 실제 돈은 나가지 않아요. 끝나면 이름 전체가 열려요.
3. **다시 보기**: 새로고침하거나 '검색 기록'에서 다시 들어가도 열려 있어야 해요.
4. **조건 바꾸기**: 위의 계산 기준을 '실용 작명법'으로 바꾸면 다시 3개만 보이고 결제 안내가 나와야 해요.
5. **관리자**: 관리자 Google 계정으로 로그인 → 잠긴 화면에서 '이 분석 전체 보기' → 결제 화면 아래 **관리자 번호 받기** → 휴대폰 ntfy 알림에 온 6자리를 넣고 **확인** → 전부 열려요. 계정 메뉴에 '관리자 모드 켜짐'이 보여요.
6. **관리자 모드 끄기**: 계정 메뉴 → '관리자 모드 켜짐' → '관리자 모드 끄기'를 누르면 일반 사용자와 똑같이 보여요.

## 8단계. 옛 주소 내리고 저장소 감추기 (7단계가 다 된 뒤에)

지금 주소(makerskim.github.io/aidam)는 결제 없이 전부 열려 있어요. 유료로 열 때 꼭 내려야 해요.

1. 저장소 **Settings → Pages → Unpublish site**를 눌러요.
2. **Settings → General** 맨 아래 **Danger Zone → Change visibility → Change to private**를 누르고, 안내대로 저장소 이름을 입력해 확인해요.

비공개로 바꾸면 소스 코드와 예전 기록(관리자 이메일 포함)이 다른 사람에게 보이지 않아요.

## 9단계. 실제 결제 받기 (사업자등록 후)

1. 홈택스에서 **사업자등록**을 해요(전자상거래·통신판매). 구청에 **통신판매업 신고**도 해요.
2. 토스페이먼츠에서 **전자결제 가입 신청**을 해요. 심사 때 사이트에 상호·대표자·사업자등록번호·통신판매업 신고번호·연락처·환불 정책이 보여야 해요. 이 정보를 알려 주시면 사이트 아래에 넣어 드려요(`apps/web/src/business.ts`).
3. 카카오페이 등 간편결제는 가입 신청 때 함께 골라요.
4. 심사가 끝나면 토스의 **라이브 키**(`live_ck_…`, `live_sk_…`)로 4단계의 `TOSS_CLIENT_KEY`와 `TOSS_SECRET_KEY`를 바꾸고, 5단계처럼 다시 배포해요.
5. 결제 화면의 환불 안내 문구(`apps/web/src/pages/Pay.tsx`)는 초안이에요. 실제 정책을 알려 주시면 고쳐 드려요.

## 무료로 쓰지 못하게 막은 것

| 막은 것 | 방법 |
|---|---|
| 결제 금액을 바꿔 결제 | 금액은 서버가 정하고, 승인할 때 주문자·금액을 다시 대조해요 |
| 서버 답을 가짜로 바꿔 잠금 풀기 | 서버가 비밀 키로 **서명**한 결제 내역·관리자 모드만 사이트가 인정해요 |
| 관리자인 척하기 | 관리자 이메일은 비밀값에 있고, Google이 인증한 이메일 + 휴대폰으로 받은 번호가 둘 다 맞아야 해요 |
| 관리자 번호 알아내기 | 번호는 매번 새로 만들고 5분 뒤 사라져요. 서버에도 번호 자체는 남기지 않고, 다섯 번 틀리면 버려요 |
| 소스 코드를 보고 고치기 | 저장소를 비공개로 바꾸고(8단계), 배포본은 압축된 코드만 나가요 |

**남는 한계**: 이름 계산은 빠르게 보여 주려고 이용자 브라우저 안에서 돌아가요. 그래서 개발 지식이 있는 사람이 압축된 코드를 직접 뜯어고치면 잠금 화면을 건너뛸 수 있어요. 이것까지 막으려면 계산을 서버로 옮겨야 하고, Cloudflare Workers 유료 요금제(월 약 $5)가 필요해요. 원하면 그렇게 바꿀 수 있어요.

## 알아 둘 점
- **환불**: 토스페이먼츠 상점관리자에서 결제를 취소하면 돼요. 그 분석을 다시 잠그려면 Cloudflare 대시보드 → Workers KV → `keys:<사용자 uid>`에서 해당 열쇠를 지워요.
- **AI 풀이**는 API를 쓰지 않아요. 일반 사용자는 '내 Claude 계정으로 풀이 받기'(요청 글 복사), 관리자는 내 컴퓨터의 Claude Code 연결(`docs/claude-bridge.md`)을 써요.
- 이 배포 설정, 실제 결제, 휴대폰 알림·문자 발송은 계정이 없어 실제로 돌려 보지는 못했어요. 자동 테스트로 확인한 것은 서버 로직과 화면 동작이에요. 처음 실행에서 막히면 오류 글을 그대로 알려 주세요.
