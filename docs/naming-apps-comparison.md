# 다른 작명 앱·사이트와 아이담의 차이 (2026-11-05 조사)

앱 제작사 소개·스토어 설명·작명 블로그를 검색해 정리했다. 점수 산식의 세부 가중치는 어느 서비스도 공개하지 않아서, "무엇을 보느냐"까지만 비교할 수 있다.

## 1. 다른 서비스가 보는 항목

| 항목 | 흔한 방식 | 예시 |
|---|---|---|
| 사주 보완 | **사주 여덟 글자에서 적은(없는) 오행을 세어 채운다**. 전문 작명가는 억부·조후 용신을 쓰기도 함 | 이름다움: "자원오행으로 사주의 부족한 오행을 보완" / 명작명: "필요한 오행(중심오행) 확인" |
| 자원오행 | 한자의 부수·본뜻으로 오행을 정함. 부수와 뜻이 다를 때 어느 쪽을 따르는지 서비스마다 다름 | 사주코드·브런치 자원오행 표 |
| 발음오행 | 자음 첫소리(일부는 받침까지)로 오행을 정해 상생을 봄. **운해본(ㅇ=土, ㅁ·ㅂ·ㅍ=水)을 쓰는 곳이 많음** | 이름다움: "종성까지 고려" |
| 수리 | 81수리 원·형·이·정 4격, **원획** 기준 | 하이작명·명작명 자동 계산 |
| 수리오행 | 4격 획수 끝자리로 오행을 정해(1·2=木, 3·4=火…) 상생을 봄 | 네임소프트 "수리길흉·수리오행·발음오행·자원오행" |
| 발음음양 | 모음·획수의 음양 균형 | 길네임·이루미 |
| 한자 거르기 | 불용한자, 흉한 뜻, 장남·장녀 전용 한자 | 네임소프트 |

## 2. 아이담과 결과가 달라지는 이유 (영향이 큰 순)

1. **용신을 정하는 방법**: 아이담은 억부용신(세력의 강약)과 조후(계절)로 정한다. 많은 앱은 "없는/적은 오행 채우기"를 쓴다. 사주가 강한데 그 강한 오행이 '적어 보이는' 경우 두 방식이 반대로 나온다.
2. **발음오행 학설**: 아이담 점수는 해례본(ㅇ·ㅎ=水, ㅁ·ㅂ·ㅍ=土), 많은 앱은 운해본(반대). ㅇ·ㅁ·ㅂ·ㅍ·ㅎ이 들어간 이름은 소리 점수가 뒤집힐 수 있다.
3. **수리오행**: 아이담은 4격의 길흉만 보고 4격끼리의 오행 상생(수리오행)은 점수에 넣지 않는다. 이를 보는 앱에서는 감점될 수 있다.
4. **자원오행 판정**: 같은 한자라도 부수 기준이냐 뜻 기준이냐에 따라 오행이 다를 수 있다(예: 京, 亞 등 부수가 오행과 무관한 글자).
5. **가중치**: 어떤 항목을 몇 점으로 보는지가 공개되어 있지 않아, 같은 항목을 봐도 총점은 다르다.

## 3. 보는 사람이 기준을 고르게 함 (v1.12)

결과·풀이 화면 위 **'계산 기준'**에서 항목마다 두 가지 중 고른다. 묶음 두 개를 한 번에 고를 수도 있다.

| 항목 | 정통 성명학 (기본) | 일반 작명앱 |
|---|---|---|
| 용신 정하는 법 | 억부·조후 | 부족한 오행(여덟 글자 중 적은 오행) |
| 발음오행 | 해례본 | 운해본 |
| 수리오행 | 가볍게(수리 25점 중 3점) | 중요하게(8점) |
| 한자오행 | 부수 기준 | 부수 기준 (뜻 기준은 따로 고를 수 있음) |

풀이 화면에는 같은 이름을 **두 기준으로 매긴 점수**를 나란히 보여 주고, 누르면 그 기준으로 자세한 풀이를 다시 보여 준다.

## 4. 결과를 비슷하게 맞추려면

| 방법 | 효과 | 상태 |
|---|---|---|
| 없는 오행을 채우는 한자에 가산점 | '부족 오행' 방식 앱과 어긋남이 줄어듦 | **적용함 (엔진 1.5.0)** |
| 기신·구신 오행 한자 빼기, 용신·희신 한자 1개 이상 | 어느 방식으로 봐도 '사주와 부딪힘'이 덜 나옴 | **적용함 (엔진 1.5.0)** |
| 해례본·운해본 둘 다 상극 없는 이름만 추천 | 어느 학설 앱에 넣어도 소리 감점이 없음 | 설정에 있음(끄고 켜기). **기본값으로 켜는 것을 권함** — 대신 후보가 줄어듦 |
| 수리오행 비중 키우기 | 수리오행을 보는 앱과 맞춰짐 | **고를 수 있음** (계산 기준 → 수리오행 '중요하게') |
| 한자오행 부수/뜻 기준 | 판정 차이 확인 | **고를 수 있음** (계산 기준 → 한자오행) |
| 기준이 같은 앱과 직접 비교 | 차이 원인 확인 | 비교하고 싶은 앱 이름과 결과 화면을 주면 항목별로 대조 가능 |

결론: 서비스마다 이론 자체가 달라 **모든 앱과 똑같이 맞추는 것은 불가능**하다. 대신 "어느 기준으로 봐도 나쁘지 않은 이름"(용신·부족 오행 모두 충족, 두 학설 모두 상극 없음, 수리오행 상생)을 고르면 어느 앱에 넣어도 비슷하게 좋은 점수가 나온다.
