# 아이담 설정 안내 (처음부터 순서대로)

코드는 다 들어가 있어요. 아래는 계정을 만들고 값을 넣는 일이라 직접 해 주셔야 해요. 1~8단계를 순서대로 하면 1~2시간 안에 끝나고, 모두 무료예요.

메모장을 하나 열어 두고, 복사한 값을 **값 ①**, **값 ②** … 번호와 함께 적어 두세요.

## 어떻게 동작하나요

| 구분 | 내용 |
|---|---|
| 로그인 | Google, 카카오. 로그인 없이도 이름을 3개까지 볼 수 있어요 |
| 요금 | 계정마다 **첫 분석 1회 무료**. 그 뒤 조건을 바꾼 새 분석은 **1회 990원** |
| 1회 | 분석 1건 = "성 + 아이 정보(성별·생일·시각·지역) + 이름 조건 + 계산 기준" 한 묶음. 연 분석은 언제든 다시 볼 수 있고, 하나라도 바꾸면 새 분석이에요 |
| 결제 | 토스페이먼츠 결제창(카드·카카오페이·네이버페이·토스페이). **지금은 뼈대만** 있고 '준비 중'으로 보여요. 사업자 등록 뒤 키만 넣으면 켜져요(9단계) |
| 관리자 | 관리자 계정도 화면은 똑같이 잠겨 있어요. 결제 화면에서 **관리자 번호**(휴대폰으로 받는 일회용 6자리)를 넣으면 12시간 동안 결제 없이 전부 봐요 |
| 출시 전 잠금 | 문을 열기 전에는 **관리자 Google 계정만** 사이트에 들어올 수 있어요. 다른 사람에게는 '준비 중' 화면만 나가요 |
| AI 풀이 | API를 쓰지 않아요(비용 0원). 일반 사용자는 요청 글을 복사해 자기 Claude에 붙여 넣고, 관리자는 내 컴퓨터의 Claude Code(구독)로 화면에서 바로 받아요(`docs/claude-bridge.md`) |
| 서버 | Cloudflare Workers + D1(무료 요금제). 사이트와 서버가 한 주소에서 나가요 |

---

## 1단계. Cloudflare 가입하고 값 두 개 복사하기

1. https://dash.cloudflare.com/sign-up 에서 이메일·비밀번호로 가입하고, 받은 메일의 확인 링크를 눌러요.
2. 왼쪽 메뉴 **Workers & Pages**(또는 Compute → Workers & Pages)를 눌러요. 처음이면 하위 도메인 이름을 정하라고 나와요. 영문 소문자로 정해요(예: `abc`). 화면 오른쪽 **Subdomain**에서 확인할 수 있어요.
3. 내 사이트 주소는 `https://aidam.<하위 도메인>.workers.dev` 예요(예: `https://aidam.abc.workers.dev`). 메모해요. → **값 ① 사이트 주소**
4. 같은 화면 오른쪽의 **Account ID**를 복사해요. → **값 ②**
5. 오른쪽 위 사람 아이콘 → **My Profile** → 왼쪽 **API Tokens** → **Create Token**.
6. **Edit Cloudflare Workers** 줄의 **Use template**을 눌러요.
7. Permissions 목록에 **D1 / Edit**가 없으면 **+ Add more**를 눌러 `Account` / `D1` / `Edit`를 추가해요. (저장소를 만들 때 필요해요.)
8. **Account Resources**는 `Include` / 내 계정, **Zone Resources**는 `Include` / `All zones`로 고르고 **Continue to summary** → **Create Token**.
9. 화면에 나온 긴 글자를 복사해요. 이 화면을 닫으면 다시 볼 수 없어요. → **값 ③**

## 2단계. Google 로그인 만들기

1. https://console.cloud.google.com 에 관리자로 쓸 Google 계정으로 들어가요.
2. 위쪽 프로젝트 고르기에서 **aidam**(예전에 만든 프로젝트)을 고르거나 **새 프로젝트**를 만들어요.
3. 왼쪽 메뉴(☰) → **API 및 서비스** → **OAuth 동의 화면**(화면에 따라 "Google 인증 플랫폼"이라고 나와요) → **시작하기**.
   - 앱 이름: `아이담`, 사용자 지원 이메일: 내 이메일
   - 대상: **외부**
   - 연락처 이메일: 내 이메일 → 동의하고 **만들기**
4. 왼쪽 **클라이언트**(또는 "사용자 인증 정보" → "사용자 인증 정보 만들기" → "OAuth 클라이언트 ID") → **클라이언트 만들기**.
   - 애플리케이션 유형: **웹 애플리케이션**, 이름: `아이담`
   - **승인된 리디렉션 URI**에 `값 ①` 뒤에 `/api/auth/google/callback`을 붙여 넣어요.
     예: `https://aidam.abc.workers.dev/api/auth/google/callback`
   - **만들기**
5. 나온 **클라이언트 ID**와 **클라이언트 보안 비밀번호**를 복사해요. → **값 ④**, **값 ⑤**
6. 왼쪽 **대상**(Audience)에서 게시 상태가 "테스트 중"이면 **테스트 사용자**에 내 이메일을 추가해요. 테스트 중에는 여기 넣은 사람만 로그인돼요. 정식으로 열 때 **앱 게시**를 눌러요(9단계).

## 3단계. 카카오 로그인 만들기

1. https://developers.kakao.com 에 카카오 계정으로 로그인해요.
2. **내 애플리케이션** → **애플리케이션 추가하기**. 앱 이름 `아이담`, 회사명은 내 이름을 넣고 저장해요.
3. 만든 앱을 눌러 **앱 키**에서 **REST API 키**를 복사해요. → **값 ⑥**
4. 왼쪽 **카카오 로그인**에서 **활성화 설정**을 **ON**으로 바꿔요.
5. 같은 화면 **Redirect URI**에 `값 ①` 뒤에 `/api/auth/kakao/callback`을 붙여 등록해요.
   예: `https://aidam.abc.workers.dev/api/auth/kakao/callback`
6. 왼쪽 **동의항목**에서 **닉네임**을 "필수 동의", **프로필 사진**을 "선택 동의"로 설정해요.

메뉴 이름은 카카오 화면이 바뀌면서 조금 다를 수 있어요. 찾기 어려우면 화면을 캡처해 알려 주세요.

## 4단계. 관리자 번호를 받을 휴대폰 준비하기

1. 휴대폰의 Play 스토어나 App Store에서 **ntfy** 앱을 설치해요.
2. 앱을 열고 **+** 버튼을 눌러요.
3. **Topic name**에 남이 맞히기 어려운 긴 이름을 영문·숫자로 지어 넣어요. `aidam-` 뒤에 아무 글자나 20자 이상 붙이면 돼요.
4. **Subscribe**를 누르고, 알림 허용을 물으면 허용해요.
5. 지은 이름을 메모해요. → **값 ⑦**

이 이름을 아는 사람은 번호를 볼 수 있으니 다른 곳에 적지 마세요. 번호가 새어도 관리자 Google 계정으로 로그인한 사람만 쓸 수 있어요.

<details>
<summary>문자(SMS)로 받고 싶을 때 (선택, 건당 요금)</summary>

[솔라피](https://solapi.com)에 가입해 **발신번호 등록**과 **충전**을 하고 **API Key / API Secret**을 만들어요. 5단계 Secrets에 아래 네 개를 더 넣으면 알림 대신 문자로 가요.

| 이름 | 값 |
|---|---|
| `SOLAPI_API_KEY` | 솔라피 API Key |
| `SOLAPI_API_SECRET` | 솔라피 API Secret |
| `SMS_FROM` | 등록한 발신번호(숫자만) |
| `ADMIN_PHONE` | 번호를 받을 내 휴대폰(숫자만) |

</details>

## 5단계. GitHub에 값 넣기

1. https://github.com/makerskim/aidam 에 로그인한 채로 들어가요.
2. 위쪽 **Settings** → 왼쪽 **Secrets and variables** → **Actions**.
3. **Variables** 탭 → **New repository variable**로 하나 넣어요.

| Name | Value |
|---|---|
| `CLOUDFLARE_ACCOUNT_ID` | 값 ② |

4. **Secrets** 탭 → **New repository secret**으로 아래를 하나씩 넣어요.

| Name | Secret |
|---|---|
| `CLOUDFLARE_API_TOKEN` | 값 ③ |
| `ADMIN_EMAILS` | 관리자로 쓸 내 Google 계정 이메일 |
| `GOOGLE_CLIENT_ID` | 값 ④ |
| `GOOGLE_CLIENT_SECRET` | 값 ⑤ |
| `KAKAO_REST_KEY` | 값 ⑥ |
| `NTFY_TOPIC` | 값 ⑦ |

이름은 대문자·밑줄까지 똑같이 넣어야 해요. 값은 채팅이나 코드에 붙여 넣지 말고 여기에만 넣어 주세요.

## 6단계. 배포하기

1. 저장소 위쪽 **Actions** 탭 → 왼쪽 **Cloudflare** → 오른쪽 **Run workflow** → 초록색 **Run workflow**.
2. 3~5분 기다려요. 맨 위 줄에 초록색 체크가 뜨면 성공이에요. 빨간 X면 그 줄을 눌러 나오는 오류 글을 그대로 알려 주세요.

이때 저장소(D1)와 서명 키가 자동으로 만들어져요. 앞으로는 코드가 바뀔 때마다 자동으로 다시 배포돼요.

## 7단계. 확인하기 (출시 전 잠금 상태)

`값 ①` 주소로 들어가요.

1. **잠금**: '준비 중이에요' 화면만 보이면 정상이에요. 휴대폰이나 다른 브라우저로 들어가도 이 화면만 보여야 해요.
2. **관리자 로그인**: '관리자 로그인' → 내 Google 계정으로 로그인하면 사이트가 열려요.
3. **무료 1회**: 이름을 추천받으면 3개만 보여요. '무료 1회로 이 분석 전체 보기'를 누르면 전체가 열려요.
4. **조건 바꾸기**: 계산 기준을 '실용 작명법'으로 바꾸면 다시 3개만 보이고 '이 분석 전체 보기 990원'이 나와요. 누르면 결제 화면에 '결제는 준비 중이에요'가 보여요.
5. **관리자 번호**: 결제 화면 아래 **관리자 번호 받기** → 휴대폰 ntfy 알림에 온 6자리를 넣고 **확인** → 전부 열려요. 계정 메뉴에 '관리자 모드 켜짐'이 보여요.
6. **관리자 모드 끄기**: 계정 메뉴 → '관리자 모드 켜짐' → '관리자 모드 끄기'.

## 8단계. 저장소 감추기

지금 저장소는 누구나 소스 코드를 볼 수 있어요. 7단계까지 확인한 뒤 감춰요.

1. 저장소 **Settings → General** 맨 아래 **Danger Zone → Change visibility → Change to private** → 안내대로 저장소 이름을 입력.

예전 공개 주소(makerskim.github.io/aidam)는 이미 '준비 중' 화면으로 바뀌어 있어요. 비공개로 바꾸면 그 주소는 아예 없어져요.

## 9단계. 정식으로 열기 (사업자 등록 뒤)

1. 홈택스에서 **사업자등록**(전자상거래·통신판매)을 하고, 구청에 **통신판매업 신고**를 해요.
2. 사업자 정보(상호·대표자·사업자등록번호·통신판매업 신고번호·주소·연락처)와 환불 정책을 알려 주세요. 사이트 아래와 결제 화면에 넣어 드려요.
3. https://developers.tosspayments.com 에 가입해 **전자결제 가입 신청**을 해요. 카카오페이 등 간편결제도 이때 골라요.
4. 먼저 **테스트 키**로 시험해요. 내 개발정보 → **API 개별 연동 키**('결제위젯 연동 키'가 아니에요)에서
   - 클라이언트 키(`test_ck_…`) → GitHub **Variables**에 `TOSS_CLIENT_KEY`
   - 시크릿 키(`test_sk_…`) → GitHub **Secrets**에 `TOSS_SECRET_KEY`
   를 넣고 6단계처럼 다시 배포해요. 결제 화면에 '시험 결제'가 보이고 실제 돈은 나가지 않아요.
5. 심사가 끝나면 같은 자리에 **라이브 키**(`live_ck_…`, `live_sk_…`)로 바꿔 넣고 다시 배포해요.
6. Google 로그인 화면(2단계 6번)에서 **앱 게시**를 눌러 누구나 로그인할 수 있게 해요.
7. 문 열기: GitHub **Variables**에 `SITE_MODE` = `open`을 넣고 다시 배포해요. 이제 누구나 들어올 수 있어요. 다시 닫으려면 `closed`로 바꿔요.

## 보안: 막은 것과 남는 한계

| 막은 것 | 방법 |
|---|---|
| 출시 전에 다른 사람이 쓰기 | 서버가 관리자 로그인을 확인한 뒤에만 사이트 파일을 줘요. 그 밖에는 '준비 중' 화면만 나가요 |
| 로그인 가로채기 | 로그인 상태는 자바스크립트가 읽지 못하는 쿠키에 있고, 서버에는 쿠키 값의 해시만 둬요 |
| 다른 사이트가 내 로그인으로 요청 보내기 | 바꾸는 요청은 같은 주소에서 온 것만 받아요 |
| 무료 1회를 여러 번 쓰기 | 서버가 계정마다 한 번만 허락해요(동시에 여러 번 눌러도 한 번) |
| 결제 금액을 바꿔 결제 | 금액은 서버가 정하고, 승인할 때 주문자·금액을 다시 대조해요 |
| 서버 답을 가짜로 바꿔 잠금 풀기 | 서버가 비밀 키로 서명한 답만 사이트가 인정해요 |
| 관리자인 척하기 | Google이 확인한 이메일 + 휴대폰으로 받은 일회용 번호가 둘 다 맞아야 해요 |
| 마구 요청 보내기 | 로그인·주문·저장 요청 횟수를 제한해요 |

**남는 한계**
- 이름 계산은 빠르게 보여 주려고 이용자 브라우저 안에서 돌아가요. 문을 연 뒤에는 개발 지식이 있는 사람이 압축된 코드를 직접 뜯어고쳐 잠금 화면을 건너뛸 수 있어요. 이것까지 막으려면 계산을 서버로 옮겨야 하고, Cloudflare Workers 유료 요금제(월 약 $5)가 필요해요.
- 무료 1회는 계정마다예요. 계정을 여러 개 만들면 그만큼 무료로 쓸 수 있어요.
- 저장소가 공개인 동안에는 소스 코드를 누구나 받아 갈 수 있어요(8단계).

## 알아 둘 점
- 가격은 `apps/worker/wrangler.toml`의 `PRICE_KRW`, 관리자 모드 시간은 `ADMIN_PASS_HOURS`에서 바꿔요.
- 환불은 토스페이먼츠 상점관리자에서 결제를 취소해요. 그 분석을 다시 잠그려면 Cloudflare 대시보드 → D1 → aidam → `tickets` 표에서 해당 줄을 지워요.
- 서버 로직과 화면 흐름은 이 컴퓨터에서 실제 서버를 띄워 시험했어요. Cloudflare 배포, 실제 Google·카카오 로그인, 실제 토스 결제, 실제 휴대폰 알림은 계정이 없어 돌려 보지 못했어요. 처음 실행에서 막히면 오류 글을 그대로 알려 주세요.
