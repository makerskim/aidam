# 아이담 작명 알고리즘 (엔진 1.9.0)

이 문서는 아이담이 이름을 고르고 점수를 매기는 방법 전체를 적은 명세다. 코드는 `packages/engine/src`, 웹 화면은 `apps/web/src`.

## 0. 원칙

- **재현성**: 난수를 쓰지 않는다. 같은 입력·같은 계산 기준·같은 엔진 버전이면 언제나 같은 목록·같은 점수·같은 풀이 글이 나온다. 정렬에는 항상 끝까지 정해진 순서(점수 → 느낌 → 이름 한글 코드 → 한자 코드)를 쓴다. 풀이 글의 문장 고르기도 이름에서 계산한 고정 값(FNV 해시)으로 정한다.
- **추천 = 풀이**: 추천 목록의 점수는 같은 이름을 '정한 이름 풀어보기'로 넣었을 때의 점수와 똑같다(같은 함수 `analyzeName`).
- **정밀성**: 만세력은 천문 계산(입춘·절입 시각), 서울 표준시 변천·서머타임, 진태양시 보정을 쓰고 한국천문연구원 자료와 1900~2050년 날마다 맞춰 봤다(`docs/manse-algorithm.md`). 획수는 원획, 한자는 대법원 인명용 한자만 쓴다.
- **검증**: `packages/engine/test/simulation.test.ts`가 무작위(시드 고정) 160가지 추천, 400가지 직접 풀이, 24가지 다둥이 세트를 돌려 아래 '9. 지켜야 할 규칙'을 확인한다.

# 계산 기준: 정통 성명학 / 실용 작명법

정통 성명학은 억부·조후 용신과 훈민정음 해례본을 따르는 전통 방식, 실용 작명법은 시중 작명 앱·작명소에서 널리 쓰는 '부족한 오행 채우기·운해본·수리 중심' 방식이다. 두 기준은 아래 네 가지에서 다르고, 나머지(만세력, 4격 계산, 원획, 81수리 길흉표, 인명용 한자, 어색한 이름 거르기)는 같다.
결과·풀이 화면의 '계산 기준'에서 묶음으로 고르거나 항목마다 따로 고를 수 있다. 코드: `packages/engine/src` (`SchoolOptions`).

| 항목 | 정통 성명학 (기본) | 실용 작명법 | 옵션 |
|---|---|---|---|
| ① 용신 정하는 법 | 억부·조후 | 부족한 오행 | `yongsinMethod`: `eokbu` / `lacking` |
| ② 발음오행 | 해례본 | 운해본 | `soundSchool`: `haerye` / `unhae` |
| ③ 배점(수리오행 포함) | 정통 배점 | 실용 배점 | `scoring`: `classic` / `app` |
| ④ 한자오행 | 부수 기준 | 부수 기준 | `hanjaElement`: `radical` / `meaning` |

## ① 용신

**억부·조후 (`analyzePillars`)**
1. 세력: 연간·월간·시간 각 10, 연지 10, 월지 30, 일지 20, 시지 10(지장간 본기 기준)으로 오행 세력(%)을 낸다.
2. 일간을 돕는 비겁+인성 비율로 강약: 아주 약함 / 약함 / 균형 / 강함 / 아주 강함.
3. 약하면: 관성·식상·재성 중 가장 센 것이 재성이면 비겁이 용신·인성이 희신, 아니면 인성이 용신·비겁이 희신.
4. 강하면: 비겁 ≥ 인성이면 관성(5% 이상일 때) 또는 식상이 용신·재성이 희신. 인성이 더 크면 재성이 용신·식상이 희신.
5. 균형이면: 겨울(해·자·축월) 불 10% 미만 → 불, 여름(사·오·미월) 물 10% 미만 → 물(조후). 아니면 가장 약한 오행이 용신·그것을 낳는 오행이 희신.
6. 강약이 치우쳤는데 조후 오행이 모자라면 희신으로 올린다(기신 쪽이면 참고만).
7. 기신 = 용신을 누르는 오행, 구신 = 기신을 낳는 오행, 나머지는 한신.

**부족한 오행 (`lackingMethod`)**
1. 사주 여덟 글자(시간 모르면 여섯 글자)의 오행 개수를 센다.
2. 적은 순서(같으면 세력이 약한 쪽, 그다음 목·화·토·금·수 순)로 줄 세운다.
3. 1번째 = 용신, 2번째 = 희신, 3번째 = 한신, 4번째 = 구신, 5번째(가장 많음) = 기신.

두 방법 모두 추천에서는 기신·구신 오행의 한자를 빼고, 용신·희신 오행의 한자를 하나 이상 담는다.

## ② 발음오행

이름 첫소리(초성)로 오행을 정하고, 성 → 이름 순서로 이웃한 두 글자의 관계를 본다(상생 1, 역상생 0.8, 같음 0.6, 상극 0).

| 초성 | 해례본 | 운해본 |
|---|---|---|
| ㄱ·ㅋ | 목 | 목 |
| ㄴ·ㄷ·ㄹ·ㅌ | 화 | 화 |
| ㅇ·ㅎ | **수** | **토** |
| ㅅ·ㅈ·ㅊ | 금 | 금 |
| ㅁ·ㅂ·ㅍ | **토** | **수** |

## ③ 배점 (합 100)

| 영역 | 정통 배점 | 실용 배점 |
|---|---|---|
| 한자오행 × 용신 | 30 | 25 |
| 수리 4격 길흉 (원·형·이·정 5·5·5·7 비율) | 22 | 25 |
| 수리오행 (4격 수 끝자리 오행의 상생) | 3 | 15 |
| 발음오행 | 20 | 20 |
| 음양 (획수 홀짝 6 + 모음 4 비율) | 10 | 15 |
| 뜻·발음 실용 (좋은 뜻 5, 불용한자 3, 발음 변화·놀림 4, 느낌 3) | 15 | 0 (부정 뜻·놀림 이름은 거르기만) |

- 한자오행 점수 = 이름 한자 오행의 선호도 평균(용신 1, 희신 0.8, 한신 −0.2~0.3(부족한 오행 방식은 0.2), 구신 −0.5, 기신 −1)을 0~28점으로 바꾸고, 용신 오행이 있으면 +2, 사주에 없는 오행(기신·구신 제외)을 채우면 +1(최대 30). 실용 배점은 이 점수 × 25/30.
- 등급: S 90 이상, A 80 이상, B 70 이상, C 60 이상, D 그 아래.

## ④ 한자오행

- 부수 기준: 부수가 오행을 나타내면 그 오행(木·艹·禾 → 목, 火·日 → 화, 土·山 → 토, 金·玉·石 → 금, 水·氵·雨 → 수), 성명학 통설 부수(糸 → 목, 心·人 → 화 …), 그래도 없으면 뜻 낱말, 마지막으로 원획 끝자리.
- 뜻 기준: 뜻(훈)의 낱말(하늘·빛·물·나무 …)로 먼저 정하고, 없으면 부수 기준과 같다.

## 5. 한자 후보 고르기 (`hanjaCandidates`)

음절마다 아래 순서로 거른다.
1. 그 소리로 읽는 인명용 한자. 이름 첫 글자는 두음법칙(려→여), 둘째 글자 이후 '율·열'은 률·렬 한자를 허용(서율 徐律).
2. 대표음(첫 음)이 그 소리인 한자만(다른 음으로 읽는 글자 제외), 부정 뜻 제외, 불용한자는 설정에 따라 제외.
3. 이름에 흔히 쓰거나 뜻이 좋은 한자만.
4. **이름 한자 이야기 사전**(약 400자, 사람이 뜻을 확인한 글자)에 있는 한자가 있으면 그 안에서만 고른다.
5. 사주가 있으면 기신·구신 오행 한자는 뺀다. 남는 한자가 없으면 그 소리는 쓰지 않는다.
6. 우선순위 = 자주 쓰는 한자 +2, 좋은 뜻 +1, 교육용 +0.3, 오행 추정(C) −1, + 사주 선호도. 상위 12자.

## 6. 한글 이름 후보와 단계별 넓히기 (`recommendNames`)

1. 후보 = 성별별 음절 조합 + 실제로 많이 쓰는 이름 목록(많이 쓰는·인기·개성 있는 이름).
2. 거르기: 같은 글자 반복, 성과 첫 글자가 같은 이름, 피할 음절·초성, 낱말처럼 들리는 이름, 놀림말, 성별에 안 맞는 끝소리(남자아이 …아·나·린·경·연 등 / 여자아이 …준·혁·호·석 등, 그 성별에서 많이 쓰는 이름은 예외, 돌림자가 끝 글자면 예외).
3. 이름 느낌 단계: 요즘 많이 쓰는(인기 이름 + 많이 쓰는 이름 앞 80개) / 무난한(오래 써 온 이름) / 흔하지 않은(개성 있는 이름). 성별을 모르면 남녀 공용 이름 먼저.
4. 단계별 넓히기: ① 고른 느낌의 이름 → ② 실제 이름 전체 → ③ 흔한 음절 조합 → ④ 이름 음절 조합 → ⑤ 그래도 모자라면 '아쉬운 이름 미리 빼기'를 풀어 뒤에 붙임. ①이 20개 이상이면 거기서 멈춘다. 실제 이름이 20개 이상이면 목록에 없는 조합은 내지 않는다.
5. 한글 이름마다 한자 조합을 채점해 상위 2개, 엄격 모드면 4격 흉수·소리 상극이 있는 조합 제외, 용신·희신 한자가 하나도 없는 조합 제외.
6. 한자가 같고 읽기만 다른 이름은 하나만. 점수 높은 순으로 최대 limit개.

## 7. 외자

외자로 실제로 쓰는 글자만 쓴다(여: 윤·율·솔·별·린·빈·은·연·설·온·담·진·현·민·결·단·슬·혜·정, 남: 준·윤·혁·결·율·건·훈·현·진·민·겸·담·찬·범·환·솔·한·온·강·웅·석·호·원·산). 4격은 원격 = 이름, 형격 = 성+이름, 이격 = 성, 정격 = 성+이름이고, 이격은 이름으로 바꿀 수 없으므로 엄격 기준에서 뺀다.

## 8. 다둥이

- 아이마다 따로: 아이별 사주로 각각 추천, 사주·성별이 같으면 같은 목록에서 아이마다 하나씩 고른다(같은 이름은 두 번 못 고름).
- 세트: 아이별 후보(2~3명 40개, 4명 25개, 5명 이상 16개)로 세트 점수 = 0.6 × 개별 점수 평균 + 0.4 × 쌍 궁합 평균. 4명까지는 모든 조합, 5~10명은 빔 탐색(상위 160개 부분 세트). 한 이름은 최대 3세트, 같은 한글 조합은 하나만.

## 9. 지켜야 할 규칙 (시뮬레이션으로 확인)

추천 비지 않음 · 같은 입력이면 같은 결과 · 점수 높은 순 · 같은 이름 중복 없음 · 0 ≤ 점수 ≤ 100, 등급 = 점수 구간 · 영역 점수 ≤ 영역 만점, 만점 합 100 · 추천 점수 = 직접 풀이 점수 · 글자 수·돌림자 위치 지킴 · 인명용·부정 뜻 아님·소리와 한자 일치 · 낱말 이름 없음 · 성별 끝소리 · 기신·구신 한자 없음(돌림자 제외) · 사주 세력 합 100, 다섯 역할이 하나씩 · 다둥이 세트 안 이름이 서로 다름·세트 점수순·재현.

## 10. 화면

- 결과: 고른 기준으로 추천 순서(점수순)와 점수를 낸다. '계산 기준'에서 묶음(정통 성명학·실용 작명법) 또는 항목별로 바꾼다.
- 풀이: '두 기준으로 보면'에 두 묶음 점수를 나란히, '계산 과정'에 단계별 숫자(만세력·용신 판단·한자 오행과 근거·원획과 4격·수리오행·발음 흐름·음양·합계)를 보여 준다.
