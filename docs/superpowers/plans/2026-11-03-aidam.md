# 아이담(Aidam) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 정통 성명학 4대 요소(사주·용희신, 음령오행, 자원오행, 81수리)로 아기 이름을 추천·분석하는 서버 없는 웹앱을 만든다.

**Architecture:** pnpm 워크스페이스. `packages/engine`은 DOM 의존 없는 순수 TS 엔진(만세력→사주→이름 분석→채점→추천→다둥이), `apps/web`은 React UI이며 엔진을 Web Worker로 호출한다. 원천 데이터(Unihan·libhangul)는 `data-sources/`에 사본을 두고 `tools/build-data`가 엔진용 JSON을 만든다.

**Tech Stack:** TypeScript 5, React 18.3.1, react-router-dom 6 (HashRouter), Vite 5, Vitest 2, fast-check, astronomy-engine 2.1.19, korean-lunar-calendar 0.4.0, @fontsource/gowun-dodum, Playwright(사전 설치본)

**Spec:** `docs/superpowers/specs/2026-11-03-aidam-design.md`

## Global Constraints

- 엔진에서 `Date.now()`, `new Date()`(인자 없음), `Math.random()`, `Intl`/로캘 의존 정렬 금지. 정렬 동률은 코드포인트 비교.
- 모든 결과 객체에 `engineVersion`(`1.0.0`)과 `dataVersion`(데이터 해시 8자리) 포함.
- 추천 한자는 `nameUse || edu`인 글자만. 부정 뜻 글자는 추천 제외.
- 발음오행 기본 학설 `haerye`(해례본), 두 학설 결과 항상 병기.
- 진태양시 보정 기본 켬(출생지 경도), 균시차 기본 끔, 자시 기본 `nextDay`.
- 지원 범위: 양력 1900-01-01~2100-12-31, 음력 입력 1900~2050.
- 이름(성 제외) 1~4자, 성 1~2자.
- 외부 네트워크 요청 0(폰트 자체 호스팅), CSP `default-src 'self'`.
- 초기 JS gzip 250KB 이하(엔진·데이터는 Worker 청크).
- 면책 문구: "전통 성명학 이론에 따른 참고 정보이며 과학적으로 검증된 예측이 아닙니다. 출생신고 전 대법원 인명용 한자를 확인하세요."
- 색 토큰: 배경 `#FFF9F4`, 표면 `#FFFFFF`, 주색 `#F4A28C`, 주색 진하게 `#C8553D`, 본문 `#3D3A36`, 보조 `#6E6862`, 세이지 `#8FB9A8`, 라벤더 `#B8A9D9`; 오행 木`#7FB77E` 火`#F28B82` 土`#E9C46A` 金`#B0B7C3` 水`#6FA8DC`.

1. 자정 직전·23시대 출생(자시 처리) — 일주가 옵션대로 바뀌어야 한다 → Task 5 테스트 `ziHour boundary`.
