# 내 컴퓨터의 Claude Code 연결 (관리자·개인용)

연결 프로그램을 켜면 내 컴퓨터에서 아이담이 열리고, 그 화면의 AI 풀이를 내 컴퓨터에 로그인된 **공식 Claude Code**가 구독 요금제(OAuth 로그인)로 써 줘요. API 키가 필요 없고 API 비용도 없어요. 쓴 만큼 내 Claude 요금제의 사용량에서 빠져요.

- 연결 번호가 없어요. 사이트에서 버튼 하나만 누르면 돼요.
- 관리자 계정에만 보여요. 일반 사용자의 화면에는 이 기능이 전혀 나오지 않아요.
- 브라우저 종류와 상관없이 돼요.

## 준비 (한 번만)
1. **Node.js 20 이상** 설치: https://nodejs.org 에서 LTS를 내려받아 "다음"만 눌러 설치
2. **Claude Code** 설치: 터미널(윈도우는 시작 → `cmd`, 맥은 `Cmd+스페이스` → `터미널`)에서

```bash
npm install -g @anthropic-ai/claude-code
```

3. **로그인**: 아래를 실행하고, 로그인 방법은 **Claude 계정(구독)** 쪽을 골라요. "Console"이나 "API" 쪽은 고르지 마세요(쓴 만큼 요금이 나와요). 입력 칸이 보이면 `/exit`로 나와요.

```bash
claude
```

4. **연결 프로그램 내려받기**: 사이트에 관리자 계정으로 로그인 → 오른쪽 위 계정 메뉴 → **내 Claude Code 연결** → **연결 프로그램 내려받기**. `aidam-claude-bridge.mjs`가 다운로드 폴더에 저장돼요.

## 쓸 때마다
1. 터미널에서 다운로드 폴더로 가요. 윈도우:

```bash
cd %USERPROFILE%\Downloads
```

맥:

```bash
cd ~/Downloads
```

2. 프로그램을 켜요. 터미널 창은 켜 둬요. 브라우저에 사이트의 '내 Claude Code 연결' 화면이 열려요.

```bash
node aidam-claude-bridge.mjs
```

3. 그 화면에서 **내 컴퓨터 화면 열기**를 눌러요. 주소가 `http://localhost:8765`로 바뀌고, 로그인된 채로 아이담이 열려요.
4. 그 화면에서 평소처럼 이름을 추천받거나 풀이해요. 풀이 화면의 "AI 풀이" 칸에 **내 Claude Code 연결됨**이 보이고, **'내 Claude Code로 풀이 받기'**를 누르면 20~40초 뒤 화면에 풀이가 나와요. 이어서 질문도 할 수 있어요.
5. 끌 때는 터미널에서 Ctrl+C.

## 안 될 때
| 나오는 말 | 해결 |
|---|---|
| "이미 켜져 있어요" | 전에 켠 창이 남아 있어요. 그 창을 쓰거나 닫고 다시 켜요 |
| "Claude Code가 설치되어 있지 않아요" | 준비 2번을 하고 터미널을 새로 열어요 |
| "로그인 상태를 확인해 주세요" | 준비 3번을 다시 해요 |
| "아이담 사이트에 닿지 않아요" | 인터넷 연결을 확인해요. 사이트 주소가 바뀌었다면 프로그램을 다시 내려받아요 |
| '내 컴퓨터 화면 열기'를 눌렀더니 "사이트에 연결할 수 없음" | 연결 프로그램이 꺼져 있어요. 터미널에서 다시 켜요 |
| "연결 값이 맞지 않거나 시간이 지났어요" | '내 컴퓨터 화면 열기'를 다시 눌러요(1분 안에 한 번만 쓸 수 있어요) |
| 터미널에 "node를 찾을 수 없다" | 터미널을 닫았다 다시 열어요. 그래도 안 되면 Node.js를 다시 설치해요 |
| 풀이가 1분 넘게 안 나옴 | Claude 요금제 사용 한도가 찼을 수 있어요. 잠시 뒤 다시 해요 |

## 알아 둘 점
- 프로그램을 켜 둔 **그 컴퓨터에서만** 동작해요. 휴대폰이나 다른 기기에서는 '내 Claude 계정으로 풀이 받기(복사 방식)'를 쓰면 돼요.
- '내 컴퓨터 화면 열기'는 로그인 상태를 내 컴퓨터 화면으로 한 번 넘겨 줘요. 넘기는 값은 1분 안에 한 번만 쓸 수 있어요.
- 프로그램은 내 컴퓨터 안(localhost)에서만 듣고, 자기가 연 화면에서 온 요청만 받아요. Claude 계정 정보나 토큰은 읽지 않고, 설치된 `claude` 명령을 도구를 모두 끈 채로 실행하기만 해요.
- AI 풀이 칸은 전체를 연 분석에서만 보여요. 잠긴 분석은 무료 1회나 관리자 번호로 먼저 열어요.
- 다른 사람들에게 서비스하는 AI 풀이를 내 구독으로 돌리는 용도로는 쓸 수 없어요(Anthropic 약관).
