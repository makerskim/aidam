# 내 컴퓨터의 Claude Code 연결 (개인용)

내 컴퓨터에 로그인된 **공식 Claude Code**가 구독 요금제(OAuth 로그인)로 이름 풀이를 쓰고, 아이담 화면에 바로 보여 줘요. API 키가 필요 없고 API 비용도 없어요. 쓴 만큼 내 Claude 요금제의 사용량에서 빠져요.

## 준비 (한 번만)
1. **Node.js 20 이상** 설치: https://nodejs.org
2. **Claude Code** 설치 후 로그인: 터미널에서 아래를 차례로 실행하고, 안내에 따라 Claude 계정으로 로그인해요.

```bash
npm install -g @anthropic-ai/claude-code
```

```bash
claude
```

## 쓰는 법
1. 아이담 풀이 화면 → **AI 풀이** 칸 아래 **'내 컴퓨터의 Claude Code 연결 (개인용)'** → **연결 프로그램 내려받기**
2. 내려받은 폴더에서 터미널을 열고 실행해요. 창은 켜 둔 채로 두세요.

```bash
node aidam-claude-bridge.mjs
```

3. 터미널에 나온 **연결 번호**를 아이담 화면에 넣고 **연결**을 눌러요. 번호는 이 브라우저에 저장돼요.
4. **'내 Claude Code로 풀이 받기'** 를 누르면 20~40초 뒤 화면에 풀이가 나와요. 이어서 질문도 할 수 있어요.

끌 때는 터미널에서 Ctrl+C. 다음에 쓸 때는 2번만 다시 하면 돼요(연결 번호는 그대로예요).

## 알아 둘 점
- **이 컴퓨터에서만** 동작해요. 휴대폰이나 다른 사람의 기기에서는 연결되지 않고, 그때는 '내 Claude 계정으로 풀이 받기(복사 방식)'를 쓰면 돼요.
- 결제가 켜진 사이트에서는 **관리자 계정에만** 이 연결 칸이 보여요.
- Chrome·Edge에서 돼요. 처음 연결할 때 브라우저가 '내 기기(로컬 네트워크) 접근'을 물으면 허용해 주세요. Safari는 막혀 있어요.
- 연결 프로그램은 내 컴퓨터(127.0.0.1)에서만 듣고, 아이담 주소에서 온 요청 + 연결 번호가 맞을 때만 받아요. Claude 계정 정보나 토큰은 읽지 않고, 설치된 `claude` 명령을 도구를 모두 끈 채로 실행하기만 해요.
- 사이트 주소가 바뀌었는데 연결이 안 되면 주소를 알려 주고 실행해요.

```bash
ALLOW_ORIGINS=https://내사이트주소 node aidam-claude-bridge.mjs
```

- 다른 사람들에게 서비스하는 AI 풀이를 내 구독으로 돌리는 용도로는 쓸 수 없어요(약관). 그 용도는 API 키 방식(`docs/payment-setup.md` 4번)이에요.
