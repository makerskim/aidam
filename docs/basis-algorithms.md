# 계산 기준 알고리즘: 정통 성명학 / 일반 작명앱 (엔진 1.7.0)

같은 입력이면 언제나 같은 결과가 나온다(난수 없음). 두 기준은 아래 네 가지에서 다르고, 나머지(만세력, 4격 계산, 원획, 81수리 길흉표, 인명용 한자, 어색한 이름 거르기)는 같다.
결과·풀이 화면의 '계산 기준'에서 묶음으로 고르거나 항목마다 따로 고를 수 있다. 코드: `packages/engine/src` (`SchoolOptions`).

| 항목 | 정통 성명학 (기본) | 일반 작명앱 | 옵션 |
|---|---|---|---|
| ① 용신 정하는 법 | 억부·조후 | 부족한 오행 | `yongsinMethod`: `eokbu` / `lacking` |
| ② 발음오행 | 해례본 | 운해본 | `soundSchool`: `haerye` / `unhae` |
| ③ 배점(수리오행 포함) | 정통 배점 | 일반 앱 배점 | `scoring`: `classic` / `app` |
| ④ 한자오행 | 부수 기준 | 부수 기준 | `hanjaElement`: `radical` / `meaning` |

## ① 용신

**억부·조후 (`analyzePillars`)**
1. 세력: 연간·월간·시간 각 10, 연지 10, 월지 30, 일지 20, 시지 10(지장간 본기 기준)으로 오행 세력(%)을 낸다.
2. 일간을 돕는 비겁+인성 비율로 강약: 아주 약함 / 약함 / 균형 / 강함 / 아주 강함.
3. 약하면: 관성·식상·재성 중 가장 센 것이 재성이면 비겁이 용신·인성이 희신, 아니면 인성이 용신·비겁이 희신.
4. 강하면: 비겁 ≥ 인성이면 관성(5% 이상일 때) 또는 식상이 용신·재성이 희신. 인성이 더 크면 재성이 용신·식상이 희신.
5. 균형이면: 겨울(해·자·축월) 불 10% 미만 → 불, 여름(사·오·미월) 물 10% 미만 → 물(조후). 아니면 가장 약한 오행이 용신·그것을 낳는 오행이 희신.
6. 강약이 치우쳤는데 조후 오행이 모자라면 희신으로 올린다(기신 쪽이면 참고만).
7. 기신 = 용신을 누르는 오행, 구신 = 기신을 낳는 오행, 나머지는 한신.

**부족한 오행 (`lackingMethod`)**
1. 사주 여덟 글자(시간 모르면 여섯 글자)의 오행 개수를 센다.
2. 적은 순서(같으면 세력이 약한 쪽, 그다음 목·화·토·금·수 순)로 줄 세운다.
3. 1번째 = 용신, 2번째 = 희신, 3번째 = 한신, 4번째 = 구신, 5번째(가장 많음) = 기신.

두 방법 모두 추천에서는 기신·구신 오행의 한자를 빼고, 용신·희신 오행의 한자를 하나 이상 담는다.

## ② 발음오행

이름 첫소리(초성)로 오행을 정하고, 성 → 이름 순서로 이웃한 두 글자의 관계를 본다(상생 1, 역상생 0.8, 같음 0.6, 상극 0).

| 초성 | 해례본 | 운해본 |
|---|---|---|
| ㄱ·ㅋ | 목 | 목 |
| ㄴ·ㄷ·ㄹ·ㅌ | 화 | 화 |
| ㅇ·ㅎ | **수** | **토** |
| ㅅ·ㅈ·ㅊ | 금 | 금 |
| ㅁ·ㅂ·ㅍ | **토** | **수** |

## ③ 배점 (합 100)

| 영역 | 정통 배점 | 일반 앱 배점 |
|---|---|---|
| 한자오행 × 용신 | 30 | 25 |
| 수리 4격 길흉 (원·형·이·정 5·5·5·7 비율) | 22 | 25 |
| 수리오행 (4격 수 끝자리 오행의 상생) | 3 | 15 |
| 발음오행 | 20 | 20 |
| 음양 (획수 홀짝 6 + 모음 4 비율) | 10 | 15 |
| 뜻·발음 실용 (좋은 뜻 5, 불용한자 3, 발음 변화·놀림 4, 느낌 3) | 15 | 0 (부정 뜻·놀림 이름은 거르기만) |

- 한자오행 점수 = 이름 한자 오행의 선호도 평균(용신 1, 희신 0.8, 한신 −0.2~0.3(부족한 오행 방식은 0.2), 구신 −0.5, 기신 −1)을 0~28점으로 바꾸고, 용신 오행이 있으면 +2, 사주에 없는 오행(기신·구신 제외)을 채우면 +1(최대 30). 일반 앱 배점은 이 점수 × 25/30.
- 등급: S 90 이상, A 80 이상, B 70 이상, C 60 이상, D 그 아래.

## ④ 한자오행

- 부수 기준: 부수가 오행을 나타내면 그 오행(木·艹·禾 → 목, 火·日 → 화, 土·山 → 토, 金·玉·石 → 금, 水·氵·雨 → 수), 성명학 통설 부수(糸 → 목, 心·人 → 화 …), 그래도 없으면 뜻 낱말, 마지막으로 원획 끝자리.
- 뜻 기준: 뜻(훈)의 낱말(하늘·빛·물·나무 …)로 먼저 정하고, 없으면 부수 기준과 같다.

## 화면

- 결과: 고른 기준으로 추천 순서와 점수를 낸다.
- 풀이: 고른 기준의 점수와 함께 '두 기준으로 보면'에 두 묶음 점수를 나란히 보여 준다(누르면 그 기준으로 다시 풀이).
